Cookie Policy

Last updated September 29, 2026

The short version

“Tech-Savvies doesn’t use advertising or tracking tools, and this website doesn’t set cookies. Our host counts page visits from its server logs, without cookies.”

That count comes from Netlify Web Analytics, which reads server logs and needs no cookies. If tech-savvies.com still shows our older website, that version uses Microsoft Clarity. We’re replacing it with this one.

What cookies are

Cookies are small text files a website asks your browser to save. Sites use them to remember you or to track what you do. Browsers can also keep similar data in local storage.

How we checked

On September 29, 2026, we loaded every page in a fresh browser at phone and desktop widths, and submitted the contact form. We found no cookies and no browser storage. Our automated checks run on every change to this website and fail if one adds a cookie, browser storage or a tracking tool.

Other websites

This site links to other sites, such as grisha.studio. They have their own cookie policies.

If this changes

We’ll update this page first. We’ll ask your permission before we use any cookie that isn’t strictly necessary.

Controlling cookies in your browser

Every browser has a privacy or site settings section. There you can block cookies, delete the ones already saved, and clear a site’s stored data.
